# ℹ️ 版本信息与构建详情

### 👀 查看途径
版本号直观显示在 **窗口标题栏** 以及 **底部状态栏** 中，并附带具体的编译构建日期。

若需查看完整诊断信息：前往 **❓ 帮助 → ℹ️ 关于 MMCelt**，或直接点击状态栏中的版本号。弹窗将展示版本号、构建日期、Commit 哈希、分支名称以及最具实用价值的 —— **正在运行的二进制程序绝对路径**。

### 💻 终端命令行查看
```
mmcelt --version
```

当本地存在多个编译副本且无需启动图形界面时，该命令可帮您迅速核对版本。

### 🤔 为什么仅凭版本号往往不够？
版本号在多次迭代编译之间可能保持不变。它仅代表软件的目标发布代号，无法证明您当前启动的 **具体是哪一份二进制文件**。

当磁盘中同时存在仓库输出、U 盘便携版或工作目录副本时，极易产生混淆。构建日期、Commit 哈希及文件物理路径是唯一能够精准鉴别版本的依据。

### ⚠️ “包含未提交修改”的警告提示
若界面出现此提示，说明该程序在编译构建时，工作区尚有未提交至 Git 仓库的代码修改：该二进制文件无法与任何干净的 Git Commit 完全对齐。
