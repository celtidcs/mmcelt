# ⌨️ 快速创建与常用快捷键

MMCelt 旨在让您能够以思绪流转的速度创建并编辑分支，双手无需离开键盘。

### ⚡ 标准快捷键一览表：
| 按键 | 即时操作 |
| :--- | :--- |
| **`Tab` / `Insert`** | 在当前选中的节点下方新增 **子节点**。 |
| **`Enter`** | 在相同层级新增 **同级节点**。 |
| **`空格键` / `F2`** | 在画布节点上方直接调出就地文本编辑器。 |
| **`Delete` / `Backspace`** | 安全删除选中节点及其全部下属子分支。 |
| **`双击`** | 进入节点文本编辑模式。 |
| **`Ctrl + N`** | 新建思维导图，旧导图将保留恢复副本。 |
| **`Ctrl + S`** | 保存思维导图至本地磁盘 (`.mmcelt`)。 |
| **`Ctrl + E`** | 导出供 AI 解析的结构化 Markdown 文件 (`.md`)。 |
| **`Home`** | 将画布镜头快速对齐并居中于项目核心主旨。 |
| **`Ctrl + F`** | 将光标移至侧边栏的搜索框，并选中已输入的文字，便于搜索其他内容。 |
| **`Ctrl + Z`** | 撤销上一次更改。连续的更改会一起撤销。 |
| **`Ctrl + Y`** | 重做最近撤销的更改。也可使用 `Ctrl + Shift + Z`。 |

### ✍️ 文本输入期间，导图控制快捷键将自动让位
`Tab`、`Insert`、`Enter`、`Delete`、`Backspace`、`空格键`、`F2`、`Home` 以及 `Ctrl + N`
仅在键盘空闲未处于文本编辑状态时生效。
一旦您在任意输入框中输入文字（如节点备注、项目愿景、粘贴 AI 响应的文本框），
这些按键将严格履行常规打字行为：例如 `Backspace` 会删除单个字符，绝不会误删节点；`Home` 会把光标移到行首，不会移动导图。

`Ctrl + S`、`Ctrl + E`、`Ctrl + F`、`Ctrl + Z` 与 `Ctrl + Y` 在文本输入期间依然可用。
它们不会打乱节点结构，允许您安全地执行保存、搜索或撤销重做操作。

### 💡 专业技巧:
选中核心节点并连续按下 `Tab` 键，即可在数秒内快速搭起 4 至 5 个核心架构支柱。

### 🔍 在大型导图中查找节点

右侧面板顶部有一个搜索框。输入**标题**或**标签**的一部分，
匹配的节点会即时显示在下方列表中。
点击其中一个即可选中它，视图会平滑移动到该节点，
且**不改变缩放比例**，以保留您原本的查看细节层级。

搜索忽略大小写与变音符号：输入 `diseno` 也能找到“Diseño”。
**备注不参与搜索**：备注是长段文字，任何常用词都会返回半张导图。
结果列表最多显示 50 条；超过这个数量时，应当缩小搜索范围。

### ✏️ 右键单击节点：“节点操作”
右键单击卡片会选中它，并在该位置打开 **节点操作** 菜单，选项与 `✏️ 编辑` 菜单和检查器相同：添加子节点（`Tab` / `Insert`）、添加同级节点（`Enter`，根节点不可用）、创建交叉连接、编辑标题（`空格键` / `F2`）、删除（`Delete`），以及状态、优先级、人工控制和角色子菜单，当前值已标记。

按住右键拖动仍会移动视图，不会打开菜单。按 `Esc` 或在菜单外点击会关闭菜单且不做任何更改。导图为只读时不会打开。
