# 📤 “发送到...”、智能体控制台与实时监听

“发送到...”会准备一次受监督的会话：有官方控制台时在控制台中对话；只有 MCP 时，MMCelt 会准备好材料，由智能体从自己的界面取得。两种流程都通过 MMCelt 的 MCP 服务把工作返回思维导图。

### 👁️ 选择智能体并不会立即发送
点击某个智能体时，会先弹出完整提示词的**预览**窗口，分成以下区块：

1. **MMCelt 协议**（只读）：最低限度的完整性规则。先探索允许使用的空间，写入前先阅读人工决策，不手动修改 `.mmcelt` 文件，并通过 MCP 返回进展。它以受保护的方式显示，避免误删。
2. **项目通用规则**（可编辑）：你的中立配置，对所有智能体都相同。
3. **思维导图上下文**（只读）：由 AI 导出功能生成。它在导图中修改，导图才是它的来源。
4. **本次会话任务**（可编辑）：你现在想要达成的目标。它不会带到下一次会话。

`恢复本次会话` 把规则与任务还原成初始内容。`保存为通用规则` 是单独的按钮：只有它才会把项目配置写入 `.mmcelt/instrucciones-agente.md`。`取消` 不保存、不导出、不监听，也不留下会话档案。

### ⚖️ 优先顺序在提示词里写明
导图中的人工修正 **>** MMCelt 协议 **>** 项目规则 **>** 本次会话任务。

### 📚 原生指令只展示，不合并
如果项目根目录里有 `AGENTS.md`、`CLAUDE.md` 或 `GEMINI.md`，预览会列出它们并允许阅读，但**不会**把内容并入通用提示词：每个工具各自按自己的范围读取自己的文件，全部复制只会产生重复而冲突的规则。

### 🚀 确认之后会发生什么
按钮会准确说明操作：找到智能体控制台时显示`在控制台中启动`，没有控制台时显示`为 MCP 做准备`。第二种情况下，预览会先显示醒目的提示。

**有控制台时**，顺序是固定的，每一步成功之后才会进行下一步：

1. **保存思维导图**到它的 `.mmcelt` 文件。
2. **导出 AI 协同文档**，放在导图所在的文件夹中，后缀为 `_AI.md`。
3. **写入会话档案**。
4. 在项目文件夹中**打开智能体控制台**。
5. **启动导图监听**。

若控制台没有打开，MMCelt **不会宣布“已发送”**，不会开始监听，并把会话档案标记为失败。

**没有控制台时**——智能体的 MCP 服务器已注册，但 MMCelt 未能定位其可执行文件——其他步骤仍会执行：保存导图、导出 `_AI.md`、写入会话档案并启动监听。只跳过第四步；因为 MMCelt 没有启动进程，档案保持为**已准备**。智能体从自己的界面取得工作，并通过 MCP 返回结果。

### 🗄️ 查看旧版本项目不会修改它
旧项目文件夹可能还没有 `.mmcelt/configuracion.json`。打开预览**不会创建**它：提示词只在内存中生成。只有确认时才写入项目身份；取消后文件夹保持原样。

### 🗂️ 会话档案：`.mmcelt/sesiones`
每次确认都会新建一个以日期、智能体和标识符命名的文件夹，里面有两个文件：

- `inicio.md`：你批准的提示词原文，逐字保留。
- `sesion.json`：格式版本、标识符、UTC 日期、智能体、导图路径、检测到与已并入的来源、提示词大小以及状态（已准备、已启动或失败）。

其中不会写入任何凭据、口令或身份标识。这是属于你的本地材料。

### 🔁 重复一次会话
在项目文件夹中打开智能体控制台，请它阅读该文件夹里的 `inicio.md`。它收到的内容与第一次完全相同，不依赖剪贴板，也无需记住你当时输入了什么。这对复现问题、以及比较两个智能体对同一任务的回应都很有用。

### 🔑 登录状态由 CLI 提供，而不是 MMCelt
MMCelt 不索取、不保存、也不转换任何凭据。它依赖你已经在 `claude`、`codex` 或 `gemini` 中登录的会话。它不使用任何付费 API，不选择模型，也不决定计费。身份验证完全留在官方工具一侧。

### 🔗 MCP 与控制台是两种独立的能力
“发送到...”菜单会给每个智能体标上图标：

- ✨ **控制台与 MCP**：可以对话，也可以把工作返回导图。
- 🖥 **只有控制台**：MMCelt 找到了它的可执行文件，但 MCP 尚未注册。
- 🔗 **只有 MCP**：能返回工作，但 MMCelt 无法为它打开控制台。
- 🔌 **两者都没有**。

某个智能体显示为已通过 MCP 连接，**并不表示**可以为它打开控制台。

### 🌌 官方控制台智能体（CLI）
MMCelt 仅保留三款官方终端客户端：**Claude Code**、**Codex CLI** 与 **Gemini CLI**（后者附带账户提示）。已移除图形化客户端，以确保仅提供经过验证且易于操作的选项。

### 💻 已验证与仅实现的平台
- **Windows**：此流程已验证。MMCelt 打开新的控制台窗口；查找程序时以 `PATHEXT` 为准，因此 npm 同时留下无扩展名 Unix 脚本和 `.cmd` 启动器时会选择 Windows 启动器。
- **Linux**：适配器已实现，但**当前版本尚未完成真实流程验证**。使用 `x-terminal-emulator`、`gnome-terminal`、`konsole` 或 `xfce4-terminal` 中第一个找到的终端；都没有时只会提示，不启动程序。
- **macOS**：尚未确认。项目在这个系统上还没有经过验证的流程，也不会先行保证。

### 🔄 闭环自动热重载
当智能体通过 `mmcelt_sync_ai_progress` 更新磁盘上的思维导图时，MMCelt 会立即捕获变动，画布自动重载，呈现新的节点、状态与优先级。

### 🛡️ 未保存本地修改的保护
若你正在编辑导图且有未保存的修改，自动重载会暂停，不会覆盖你的工作。一旦你用 `Ctrl + S` 保存，它就会恢复。

### 🛑 如何停止监听与控制台
在人工智能菜单中使用 `停止跟踪`、用 `Ctrl + N` 新建导图、从 `文件` 菜单打开其他文件，或关闭应用程序，监听都会干净地结束。

智能体控制台是**独立进程**：要在它自己的窗口里关闭。停止监听不会关闭控制台，关闭控制台也不会删除会话档案。
