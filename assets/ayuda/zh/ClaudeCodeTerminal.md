# 🟣 Claude Code：MMCelt 打开控制台

Claude Code 是 Anthropic 官方的终端智能体，专为编程和直接处理本地文件而设计。

### 如何首次连接？

1. 在 MMCelt 中打开您的思维导图。
2. 进入菜单 `🤖 人工智能` → `🔌 将MMCelt连接到我的AI...`。
3. 确认项目文件夹正确无误后，点击 Claude Code 行中的**连接**按钮。
4. 如果当前有打开的 Claude Code 终端，请将其关闭并重新打开，以便其加载与 MMCelt 的新连接。

### 日常如何工作？

1. 在 MMCelt 菜单中，选择 `🤖 人工智能` → `📤 发送到...` 并选择 **Claude Code**。
2. 随后会弹出窗口，供您仔细审阅将发送给智能体的指令和上下文。
3. 点击**在控制台中启动**按钮。您无需手动打开终端：MMCelt 会自动在项目文件夹中开启新控制台，创建工作档案并在后台开启变更监听。
4. 在该终端窗口中继续与 AI 对话。当智能体在导图中提出新想法或扩展分支时，它会调用 `mmcelt_sync_ai_progress` 工具，您将看到新节点直接显示在屏幕上。

MMCelt 会直接复用您在 Claude Code 中已登录的会话，不会索取额外的 API 密钥，也不会管理您的 Anthropic 账单。
