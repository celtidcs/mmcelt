# 📊 生命状态、进度与优先级

MMCelt 中的思维导图绝非静态草图: 它是跟踪项目全局的实时动态看板。每个节点均可被赋予进度状态与优先级，帮助您一眼看清哪些已就绪、哪些正在构建，以及哪些疑问阻碍了进展。

### 🏷️ 节点的 6 种状态

选中某个节点并查看**侧边属性栏 (检查器)** (位于屏幕右侧的面版) 时，只需轻轻一点即可指定以下六种状态之一:

1. **💡 构思:** 尚未评估的初步构想或建议。这是开展头脑风暴时的完美初始状态。
2. **🔍 调研中:** 处于技术探索、文档研读或可行性分析阶段的任务与概念，尚未正式编写代码。
3. **⏳ 进行中:** 当前正在积极推进的具体工作。
4. **❓ 阻塞 / 待决:** 关键瓶颈点，因等待决策或需攻关技术难题而暂时停滞。
5. **✅ 已完成:** 已成功构建、通过测试并验证完毕的任务或组件。
6. **⛔ 已弃用:** 经过调研评估但决定不予实现的方向。将其保留在导图中并标记为已弃用具有重要参考价值，可防止后续再次重复踩坑。

**⚡ 优先级 (🔽 低、🔷 中、⚡ 高、🔥 紧急):**
在状态旁，您可以标注每个分支的紧迫程度。属性检查器菜单与画布上的节点本身都会显示这些图标:
- **🔽 低与 🔷 中:** 可选优化项、次要任务或常规日常开发工作。
- **⚡ 高:** 应当尽早交付的核心主干模块与高优先级组件。
- **🔥 紧急:** 阻碍整个项目继续推进的最高优先级关键阻塞项。

### 🤖 配合 AI 工作时状态如何发挥效力?

节点状态不仅是您眼中的颜色区分；人工智能在读取和解析时会赋予其极高权重:
- **优先解决阻塞项:** 所有标记为 **`❓ 阻塞 / 待决`** 的节点都会被归拢在导出任务文档的醒目专属区域中。AI 明确知道必须优先协助攻克这些疑难问题，而不是盲目发散新构想。
- **尊重已弃用路径:** 如果将某一分支标记为 **`⛔ 已弃用`**，AI 将明白该方案已明确遭到否决，不会反复向您兜售类似建议。
- **已完成部分充当上下文:** 标记为 **`✅ 已完成`** 的节点将告知 AI 系统哪些部分已经稳固落地并正常运转，以便其直接基于现有成果展开扩展，杜绝重复劳动。
- **全自动度量统计:** 在导出文档的头部，MMCelt 会自动汇总全局进度指标 (完成百分比、已完成与待办节点数量对比)，使大模型对项目的整体成熟阶段了然于胸。

### 💡 卡片上每个图标的含义
将鼠标悬停在图标上即可看到其含义：标题前的表情符号是 **状态**；右上角的是 **优先级** 和 **人工控制**；右下角是节点的 **角色**（“任务 / 执行项”的 ⚡ 不是高优先级的图标：悬停提示会区分它们）；底部的 📝 表示 `📝 包含备注：选中该节点即可在检查器中阅读`。拖动节点时不会显示。
