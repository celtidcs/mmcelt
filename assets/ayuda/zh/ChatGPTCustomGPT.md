# 🟢 与 Codex CLI 及 ChatGPT 集成

无论您习惯在终端命令行中操作，还是偏好在网页浏览器中对话，都可以让 OpenAI 的人工智能为 MMCelt 中的思维导图提供强大支持。

### 💻 在终端中使用 Codex CLI

Codex CLI 是一款直接运行在本地电脑上的终端智能体，这是最高效、最自动化的协作方式：

1. 进入菜单 `🤖 人工智能` → `📤 发送到...` → `Codex CLI`。
2. 您将看到包含导图内容与 AI 任务要求的完整预览，请从容审阅。
3. 点击**在控制台中启动**后，MMCelt 会自动在准备好的环境中开启终端，并在后台监听文件变更，将 Codex 创建的节点即时呈现。
4. Codex CLI 会通过 MCP 服务器读取导图与各项要求。在分析项目的过程中，它可以拓展分支、提出建议并实时更新导图。

> 💡 **提示：** 为确保 Codex CLI 能与 MMCelt 正常通信，请事先通过 `🤖 人工智能` → `🔌 将MMCelt连接到我的AI...` 完成连接；若终端此前已打开，请将其重启。

### 🌐 在网页中使用 ChatGPT 或 Custom GPT

如果您不使用终端命令行，更喜欢在浏览器中交流（使用免费版 ChatGPT、Plus 订阅或自定义 Custom GPT）：

1. 通过 `📁 文件` → `🤖 导出面向 AI 的 Markdown (.md)` 导出导图（或通过 `🤖 人工智能` → `👁️ 预览AI Markdown (.md)...` 在屏幕上预览文本）。
2. 打开浏览器访问 ChatGPT，上传 `.md` 文件或将内容直接粘贴到对话中。
3. 要求 AI 拓展导图分支、评估风险、寻找替代方案或规划具体任务。
4. 当 ChatGPT 回复后（通常会返回 JSON 或 Markdown 格式的结构化内容），将其复制。
5. 返回 MMCelt 并点击 `🤖 人工智能` → `📥 从AI导入（ChatGPT、Claude、Gemini）...`。粘贴内容并确认导入：新分支将融入导图中，且原有的全部工作均完好保留。

### 🔒 核心差异与数据隐私

请务必知悉两种使用场景在数据交互方式上的本质不同：
- **Codex CLI（本地与 MCP）：** 完全运行在您的本地设备上，通过 MCP 协议直接且仅限访问授权的项目目录。
- **网页版 ChatGPT：** 运行在 OpenAI 的云端服务器上，无法直接访问您的本地文件或 MMCelt MCP 服务。交互过程完全通过手动导出和导入 Markdown 或 JSON 文本进行，安全自主可控。
