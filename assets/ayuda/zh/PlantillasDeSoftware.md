# ✨ 软件架构模板

面对一张空白画布从零构思软件系统可能会令人无所适从。为此，MMCelt 内置了基于现代软件工程最佳实践构建的**预设架构模板**，只需一键即可随时调入使用。

这些模板并非单纯的形式草图: 它们已按严谨的逻辑分层组织妥当，搭配语义化颜色、组件间关联类型以及详实的说明备注，既能指引您的顶层设计，亦可为大模型的分析应答提供精准依据。

### 🏛️ MMCelt 现已包含的经典模板

**1. Clean Architecture (整洁架构 / 六边形架构):**
该模板助您打造健壮、高可维护且易于进行单元测试的软件系统。在此架构下，核心业务规则与具体技术细节及外部第三方类库实现全面分离。
系统划分为四层同心圆结构:
- **领域层 (核心 Domain):** 核心业务实体与固有规则，无论底层切换数据库或更换应用框架均应坚如磐石保持不变。
- **用例层 (应用 Application):** 用户或外部系统可触发的具体业务操作 (例如: 注册用户、处理订单)。
- **基础设施层 (适配器 Infrastructure):** 与外部环境的集成与通信: SQL/NoSQL 数据库持久化、外部 REST API 调用、消息总线及本地文件读写。
- **展现层 (接口与控制器 Presentation):** 系统的对外暴露入口，包括 REST 控制器、GraphQL 路由端点或图形操作界面。

*内置交叉关联线清晰展示依赖倒置原则: 外层依附于内层抽象，而内部核心绝不反向依赖外部基础设施。*

**2. Fullstack Web App (全栈现代化 Web 应用):**
特别适用于全链路规划一套现代化网络应用系统:
- **前端 (客户端 Frontend):** 用户交互界面 (动态交互组件、全局状态管理机制与排版布局)。
- **后端 (服务端 Backend):** 承载业务主逻辑的 API、鉴权认证中心、权限管控与参数校验。
- **数据库与持久层 (Persistence):** 关系型或文档型数据模型、数据库迁移脚本与高性能缓存层。
- **运维与基础设施 (DevOps):** Docker 容器编排配置、CI/CD 持续集成交付流水线与云端基础设施部署。

### 🚀 如何调入与使用模板

1. 展开顶部菜单 **`📁 文件`** → **`✨ 架构模板`**。
2. 挑选契合当前项目目标的预设方案 (**Clean Architecture** 或 **Fullstack Web App**)。
3. MMCelt 将把完整的全套节点树架构加载至画布中央。
4. 从此刻起，您可以随心定制每个分支: 增补专属数据模型、重命名内部服务、权衡轻重设定优先级，并点击 `🤖 人工智能` → `📤 发送到...` 指令代码助手严格依循此架构框架展开编码!
