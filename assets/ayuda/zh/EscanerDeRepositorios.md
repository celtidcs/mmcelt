# 🔍 代码文件夹自动扫描器

如果您的计算机上已有编程项目或包含源码的文件夹，则无需从头逐个节点手动创建思维导图。MMCelt 的**代码扫描器**可在数秒内快速解析项目结构并自动生成可交互的可视化导图。

### 🛠️ 如何使用扫描器并发挥其最大价值:

**🧠 扫描代码有什么作用?**
将文件文件夹转化为思维导图，您可以获得:
- **架构全景图谱:** 快速理清各模块、库及组件的组织方式，不再迷失在繁杂的子文件夹中。
- **文件直接关联:** 导图中的每个卡片都会关联其在磁盘上的真实路径 (`file_path`)，便于您和 AI 准确掌握每个概念对应的实体文件。
- **与 AI 协作的理想起点:** 您可以指示任何人工智能模型分析提取出的架构、检测重复代码、提出重构建议或定位循环依赖。

**使用扫描器的操作步骤:**
1. 在顶部菜单栏中，打开菜单 **`📁 文件`** → **`🔍 扫描代码文件夹...`**。
2. 弹出系统选择窗口，指定代码仓库或软件项目的根目录。
3. MMCelt 将安全高效地扫描文件夹树:
   - **过滤技术干扰:** 自动忽略体积庞大或无需概念表达的构建与依赖目录 (如 `node_modules/`、`target/`、`dist/`、`.git/`、Python 虚拟环境等)。
   - **构建层级结构:** 将主文件夹置于中心，并向外发散主要模块、包和核心源码文件。
4. 导图生成后，您可以自由调整节点布局、修改配色、添加注释说明或标记待审查区域。

**🤖 配合 AI 的后续工作:**
代码扫描完成后:
- 使用 `🤖 人工智能` → `👁️ 预览AI Markdown (.md)...` 查看架构摘要。
- 将项目发送给您常用的终端智能体 (`📤 发送到...`)，或导出后提供给网页端大模型。AI 将精确掌握每个文件的位置与脉络!
