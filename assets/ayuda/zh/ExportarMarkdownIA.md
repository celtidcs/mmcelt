# 🤖 Markdown 导出与 AI 预览

MMCelt 的核心优势之一在于能将整幅图形思维导图自动转换为结构严谨的 Markdown 文本文件。该文档经过专门设计，旨在让任何人工智能模型均能精准领会项目的层级架构、核心目标与技术细节。

### 📦 导出文档包含的内容

所生成的文本并非杂乱无章的罗列，而是遵循周密的逻辑结构:
1. **角色与指令约束:** 引导模型充当项目的系统架构师与高级技术顾问。
2. **项目愿景:** 包含您在“项目”选项卡中撰写的说明，确保 AI 时刻聚焦全局目标。
3. **状态进度概览:** 导图的核心度量指标 (待办、已完成或正在调研中的任务数量统计)。
4. **多级层级结构:** 每个节点、子任务及附加说明均按标题级别清晰展开。
5. **人类审核指令:** 明确标示哪些部分已经过人工核准，哪些部分被标记为需修正。
6. **交叉连接与依赖关系:** 描述不同分支间的关联，告知 AI 模块间的阻塞和依赖脉络。
7. **疑问与阻塞瓶颈:** 重点突出标有疑问或待决的点，引导模型优先提供解决方案。
8. **内置 Mermaid 流程图:** 纯文本图表代码，主流大模型可在对话框中直接将其渲染为可视化图形。
9. **即用型行动提示词:** 预设的常用问答模板，可一键复制至网页端对话框中 (如架构审计、阶段规划等)。

### ⚡ 实时预览与快捷导出:

**👁️ 导出前实时预览 Markdown 内容:**
如果您希望在保存至磁盘前亲自核对即将提交给 AI 的全部信息:
1. 点击顶部菜单栏的 `🤖 人工智能` → `👁️ 预览AI Markdown (.md)...`。
2. 随后将弹出一个全览窗口，您可以在此查阅完整文档、浏览各小节，并检查备注、优先级及关联线的解析效果。
3. 在此窗口中，您可以从容校对文本，亦可用鼠标直接划选复制段落。这是对共享数据保持全权掌控的理想途径。

**💾 如何导出 `.md` 文件:**
当您准备好将文档持久化存储到本地磁盘时:
- **通过文件菜单:** 按下快捷键 `Ctrl + E`，或前往 `📁 文件` > `🤖 导出面向 AI 的 Markdown (.md)`。
- **通过人工智能菜单:** 前往 `🤖 人工智能` → `💾 导出供AI使用的.md文件...`。

生成的 `.md` 文件可直接作为附件上传至 ChatGPT、Claude 或 Gemini 等网页端聊天界面，亦可在任意本地文本编辑器中直接打开查阅。
