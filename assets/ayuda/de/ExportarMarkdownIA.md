# 🤖 Markdown-Export und KI-Vorschau

Einer der großen Vorteile von MMCelt ist die automatische Umwandlung Ihrer gesamten visuellen Mindmap in ein strukturiertes Markdown-Textdokument. Dieses Dokument ist so aufgebaut, dass jedes KI-Modell die Hierarchie, den Zweck und die Details Ihres Projekts mit höchster Genauigkeit versteht.

### 📦 Was das generierte Dokument enthält

Der generierte Text ist keine ungeordnete Aufzählung, sondern folgt einer durchdachten logischen Struktur:
1. **Rolle und Richtlinien:** Weist das Modell an, als Systemarchitekt und technischer Partner Ihres Projekts zu agieren.
2. **Projektvision:** Beinhaltet die im Reiter „Projekt“ verfasste Beschreibung, damit die KI das übergeordnete Ziel stets im Blick behält.
3. **Statusübersicht:** Wichtige Kennzahlen der Map (Anzahl offener, abgeschlossener oder in Recherche befindlicher Aufgaben).
4. **Hierarchische Struktur:** Jeder Knoten, jede Teilaufgabe und jede Notiz nach Überschriftenebenen geordnet.
5. **Menschliche Vorgaben:** Zeigt unmissverständlich, welche Bereiche Sie freigegeben haben und welche noch korrigiert werden müssen.
6. **Querverbindungen und Abhängigkeiten:** Beschreibt Beziehungen zwischen Zweigen, damit die KI erkennt, was worauf aufbaut.
7. **Fragen und Blockaden:** Hebt als unklar markierte Stellen hervor, damit das Modell diese vorrangig klärt.
8. **Eingebettetes Mermaid-Diagramm:** Ein textbasiertes Flussdiagramm, das viele Web-KIs direkt visuell im Chatfenster darstellen können.
9. **Sofort nutzbare Aktions-Prompts:** Vorlagen für häufige Fragestellungen zum Kopieren in Web-Chats (technisches Audit, Phasenplanung etc.).

### ⚡ Schnelle Vorschau und Export:

**👁️ Markdown vor dem Export prüfen:**
Wenn Sie vor dem Speichern auf der Festplatte mit eigenen Augen sehen möchten, welche Daten an die KI übermittelt werden:
1. Wählen Sie im oberen Menü `🤖 Künstliche Intelligenz` → `👁️ KI-Markdown-Vorschau (.md)...`.
2. Es öffnet sich ein Fenster, in dem Sie das vollständige Dokument lesen, durch Abschnitte navigieren und die Übertragung Ihrer Notizen, Prioritäten und Verbindungen prüfen können.
3. Direkt in diesem Fenster können Sie den Text in Ruhe durchgehen oder Passagen mit der Maus kopieren. Der ideale Weg zur vollen Kontrolle über geteilte Inhalte.

**💾 So exportieren Sie die `.md`-Datei:**
Wenn Sie das Dokument auf Ihrer Festplatte speichern möchten:
- **Über Datei:** Drücken Sie `Strg + E` oder wählen Sie `📁 Datei` > `🤖 Markdown für die KI exportieren (.md)`.
- **Über Künstliche Intelligenz:** Gehen Sie zu `🤖 Künstliche Intelligenz` → `💾 .md-Datei für KI exportieren...`.

Die erzeugte `.md`-Datei können Sie direkt in Web-Chats wie ChatGPT, Claude oder Gemini hochladen oder mit einem beliebigen Texteditor öffnen.
