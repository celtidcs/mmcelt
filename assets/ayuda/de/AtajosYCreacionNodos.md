# ⌨️ Schnelle Erstellung und Tastenkombinationen

MMCelt ermöglicht es Ihnen, Zweige und Ideen in Gedankengeschwindigkeit zu erstellen, ohne die Hände von der Tastatur zu nehmen.

### ⚡ Übersicht der Standard-Tastenkombinationen:
| Taste | Sofortige Aktion |
| :--- | :--- |
| **`Tab` / `Einfg`** | Fügt einen **Kindknoten** unter dem ausgewählten Knoten hinzu. |
| **`Eingabe`** | Fügt einen **Geschwisterknoten** auf derselben Ebene hinzu. |
| **`Leertaste` / `F2`** | Öffnet den Texteditor direkt auf der Arbeitsfläche über dem Knoten. |
| **`Entf` / `Rücktaste`** | Löscht den ausgewählten Knoten und alle untergeordneten Zweige sicher. |
| **`Doppelklick`** | Aktiviert den Textbearbeitungsmodus des Knotens. |
| **`Strg + N`** | Erstellt eine neue Mindmap. Eine Wiederherstellungskopie der vorherigen bleibt erhalten. |
| **`Strg + S`** | Speichert die Mindmap auf dem Datenträger (`.mmcelt`). |
| **`Strg + E`** | Exportiert die angereicherte Markdown-Datei für KI (`.md`). |
| **`Pos1`** | Zentriert die Ansicht auf der zentralen Projektidee. |
| **`Strg + F`** | Setzt den Cursor in das Suchfeld der Seitenleiste, mit markiertem Text, um etwas anderes zu suchen. |
| **`Strg + Z`** | Macht die letzte Änderung rückgängig. Aufeinanderfolgende Änderungen werden zusammen zurückgenommen. |
| **`Strg + Y`** | Wiederholt die zuletzt rückgängig gemachte Änderung. Auch `Strg + Umschalt + Z`. |

### ✍️ Während der Texteingabe ruhen map-bezogene Tastenkombinationen
`Tab`, `Einfg`, `Eingabe`, `Entf`, `Rücktaste`, `Leertaste`, `F2`, `Pos1` und `Strg + N` wirken nur bei freier
Tastatur. Sobald Sie in einem Textfeld schreiben — Notizen eines Knotens, Vision des Projekts,
das Eingabefeld für KI-Antworten —, verhalten sich diese Tasten wie beim Schreiben üblich:
`Rücktaste` löscht ein Zeichen, nicht den Knoten, und `Pos1` setzt den Cursor an den
Zeilenanfang, ohne die Mindmap zu verschieben.

`Strg + S`, `Strg + E`, `Strg + F`, `Strg + Z` und `Strg + Y` bleiben auch während der Texteingabe aktiv.

### 💡 Profi-Tipp:
Wählen Sie den Hauptknoten aus und drücken Sie mehrmals `Tab`, um zügig 4 bis 5 strukturelle Säulen anzulegen.

### 🔍 Einen Knoten in einer großen Map finden

Oben im rechten Bereich befindet sich ein Suchfeld. Geben Sie einen Teil eines **Titels** oder
eines **Schlagworts** ein: Die passenden Knoten erscheinen darunter. Ein Klick wählt den Knoten
aus und führt die Ansicht zu ihm, **ohne den Zoom zu ändern**, damit die Detailstufe erhalten
bleibt, auf der Sie gearbeitet haben.

Groß- und Kleinschreibung sowie Akzente werden ignoriert: `diseno` findet „Diseño“. **Notizen
werden nicht durchsucht**: Sie sind lange Absätze, und jedes gebräuchliche Wort würde die halbe
Map zurückgeben. Die Liste endet bei 50 Treffern; bei mehr Treffern hilft nur, die Suche
einzugrenzen.

### ✏️ Rechtsklick auf einen Knoten: „Knotenaktionen“
Ein Rechtsklick auf eine Karte wählt sie aus und öffnet dort das Menü **Knotenaktionen** mit denselben Optionen wie das Menü `✏️ Bearbeiten` und der Inspektor: Kind hinzufügen (`Tab` / `Einfg`), Geschwister hinzufügen (`Eingabe`, nicht bei der Wurzel), Querverbindung erstellen, Titel bearbeiten (`Leertaste` / `F2`), löschen (`Entf`) sowie die Untermenüs für Status, Priorität, menschliche Kontrolle und Rolle, mit dem aktuellen Wert markiert.

Ziehen mit der rechten Taste verschiebt weiterhin die Ansicht und öffnet das Menü nicht. `Esc` oder ein Klick außerhalb schließen es, ohne etwas zu ändern. Ist die Mindmap schreibgeschützt, öffnet es sich nicht.
