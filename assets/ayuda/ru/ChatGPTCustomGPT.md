# 🟢 Интеграция с Codex CLI и ChatGPT

Используете ли вы консоль или предпочитаете браузер, вы можете применять искусственный интеллект OpenAI для работы со своими интеллект-картами в MMCelt.

### 💻 Codex CLI (в терминале)

Codex CLI — консольный агент, работающий непосредственно на вашем компьютере. Это самый быстрый и автоматизированный способ работы:

1. Откройте меню `🤖 Искусственный интеллект` → `📤 Отправить в...` → `Codex CLI`.
2. Вы увидите полный предпросмотр содержимого карты и задания для ИИ. Спокойно изучите его.
3. При нажатии кнопки **Запустить в консоли** MMCelt автоматически откроет терминал в подготовленном окружении и начнёт отслеживать изменения, добавляя созданные узлы в карту.
4. Codex CLI прочитает карту и инструкции через сервер MCP. Анализируя проект, он сможет строить ветви, предлагать идеи и обновлять карту в реальном времени.

> 💡 **Примечание:** Чтобы Codex CLI мог взаимодействовать с MMCelt, не забудьте предварительно подключить его через `🤖 Искусственный интеллект` → `🔌 Подключить MMCelt к моим ИИ...` и перезапустить терминал, если он был открыт.

### 🌐 ChatGPT в браузере или Custom GPT

Если вы не пользуетесь консолью и предпочитаете общаться в браузере (через бесплатный ChatGPT, Plus или собственный Custom GPT):

1. Экспортируйте карту через `📁 Файл` → `🤖 Экспорт Markdown для ИИ (.md)` (или просмотрите текст на экране через `🤖 Искусственный интеллект` → `👁️ Предпросмотр Markdown для ИИ (.md)...`).
2. Откройте браузер, перейдите в ChatGPT и прикрепите файл `.md` либо вставьте текст прямо в диалог.
3. Попросите ИИ развить карту, оценить риски, найти альтернативы или сформулировать задачи.
4. Когда ChatGPT ответит (как правило, структурированным блоком JSON или Markdown), скопируйте ответ.
5. Вернитесь в MMCelt и выберите `🤖 Искусственный интеллект` → `📥 Импортировать из ИИ (ChatGPT, Claude, Gemini)...`. Вставьте текст и нажмите «Импортировать»: новые ветви добавятся в карту с полным сохранением всей вашей работы.

### 🔒 Ключевые различия и конфиденциальность данных

Важно понимать разницу во взаимодействии этих двух сред с вашими данными:
- **Codex CLI (локально с MCP):** Работает на вашем компьютере и напрямую обращается к разрешённой папке проекта по протоколу MCP.
- **ChatGPT в веб-браузере:** Работает на серверах OpenAI и не имеет прямого доступа к локальным файлам или серверу MCP. Обмен происходит полностью вручную и безопасно через экспорт и импорт текста Markdown или JSON.
