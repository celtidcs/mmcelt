# 📁 Привязка файлов исходного кода (file_path)

Связывайте идеи и решения вашей интеллект-карты с реальными файлами проекта на диске.

### 🛠️ Как связать файл и для чего это нужно:

Интеллект-карта помогает мыслить масштабно: у вас может быть узел «Аутентификация пользователей» и узел «База данных». Однако компьютер и программы состоят из конкретных файлов (таких как `src/auth.rs` или `config/database.json`).

Поле файла (`file_path`) служит мостом, соединяющим абстрактную идею с реальным файлом, в котором хранится её код или документация. Благодаря этому карта становится не просто схемой, а живым указателем вашего проекта.

**Шаги для привязки файла:**
1. Нажмите на любой узел карты, чтобы выделить его.
2. Посмотрите на правую боковую панель (Инспектор узла).
3. В поле **📁 Файл/Путь:** введите путь к файлу относительно папки проекта. Например:
   - `src/login.rs` для файла исходного кода.
   - `documentacion/requisitos.md` для пояснительного текста.
   - `frontend/components/` для указания целой папки.

### 💡 Практические советы и работа с ИИ:

**🤖 Как это использует искусственный интеллект?**
Когда вы работаете с ассистентом (таким как Claude Code, Codex CLI или Gemini CLI) либо экспортируете сводку проекта в Markdown:
- ИИ точно считывает, какой файл соответствует каждому узлу.
- Он заранее знает, где вносить изменения, не тратя время на слепой поиск по всему репозиторию.
- Это помогает поддерживать чистое соответствие между концептуальной архитектурой и исходным кодом.

**Практические советы:**
- **Используйте относительные пути:** Всегда указывайте пути от корневой папки проекта (например, `src/main.rs` вместо `C:\Документы\Проект\src\main.rs`). В этом случае при перемещении папки проекта все ссылки сохранят свою работоспособность.
- **Пути к папкам:** Если узел объединяет несколько файлов, путь можно завершить косой чертой (например, `src/services/`), указав, что узел представляет весь каталог.
