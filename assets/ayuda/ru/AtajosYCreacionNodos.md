# ⌨️ Быстрое создание и горячие клавиши

MMCelt спроектирован так, чтобы создавать и редактировать ветки со скоростью мысли, не отрывая рук от клавиатуры.

### ⚡ Таблица стандартных горячих клавиш:
| Клавиша | Действие |
| :--- | :--- |
| **`Tab`** | Добавляет **дочерний узел** под выбранным узлом. |
| **`Enter`** | Добавляет **соседний узел** на том же уровне иерархии. |
| **`Пробел` / `F2`** | Открывает редактор текста прямо на холсте над узлом. |
| **`Delete` / `Backspace`** | Безопасно удаляет выбранный узел и все его дочерние ветви. |
| **`Двойной клик`** | Вход в режим редактирования текста узла. |
| **`Ctrl + N`** | Создает новую карту. Сохраняется резервная копия предыдущей. |
| **`Ctrl + S`** | Сохраняет интеллект-карту на диск (`.mmcelt`). |
| **`Ctrl + E`** | Экспортирует обогащенный файл Markdown для ИИ (`.md`). |
| **`Ctrl + F`** | Центрирует камеру на главной идее проекта. |
| **`Ctrl + Z`** | Отменяет последнее изменение. Идущие подряд изменения отменяются вместе. |
| **`Ctrl + Y`** | Повторяет последнее отменённое изменение. Также работает `Ctrl + Shift + Z`. |

### ✍️ Во время ввода текста горячие клавиши карты не перехватываются
`Tab`, `Enter`, `Delete`, `Backspace`, `Пробел`, `F2` и `Ctrl + N` действуют только тогда, когда
фокус не находится в поле ввода. Как только вы начинаете печатать текст (в примечаниях,
видении проекта или окне вставки ответа ИИ), клавиши работают стандартно:
`Backspace` стирает символ, а не удаляет узел.

`Ctrl + S`, `Ctrl + E`, `Ctrl + F`, `Ctrl + Z` и `Ctrl + Y` остаются активными во время ввода.
Они не изменяют структуру карты и позволяют безопасно сохранять данные или отменять действия.

### 💡 Совет профи:
Выберите центральный узел и нажмите `Tab` несколько раз, чтобы быстро создать 4–5 структурных модулей.

### 🔍 Как найти узел в большой карте

Вверху правой панели есть поле поиска. Введите часть **названия** или **метки** — совпадающие
узлы появятся ниже. Нажатие на узел выделяет его и переводит вид к нему, **не меняя масштаб**,
чтобы сохранился тот уровень детализации, с которым вы работали.

Регистр и диакритика не учитываются: `diseno` находит «Diseño». **Заметки не ищутся**: это
длинные абзацы, и любое частое слово вернуло бы половину карты. Список ограничен 50
результатами; если совпадений больше, стоит уточнить запрос.
