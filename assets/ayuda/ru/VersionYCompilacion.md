# ℹ️ Версия и сборка

### 👀 Где посмотреть
Номер версии отображается в **заголовке окна** и в **строке состояния** вместе с датой сборки.

Полная информация доступна в **❓ Справка → ℹ️ О программе MMCelt** либо по клику на версию в строке состояния. Отображаются версия, дата, коммит, ветка и **точный путь к запущенному исполняемому файлу**.

### 💻 Через командную строку
```
mmcelt --version
```

Полезно, когда на диске есть несколько копий и требуется проверить версию конкретного файла без запуска графического интерфейса.

### 🤔 Почему одного номера версии недостаточно?
Номер версии не меняется между промежуточными сборками. Он указывает целевой релиз, а не **точный исполняемый файл**, который был запущен.

Это важно, когда на диске сосуществуют несколько копий: в папке проекта, на флешке или во временных каталогах. Дата, коммит и путь позволяют точно идентифицировать бинарный файл.

### ⚠️ Предупреждение «несохраненные изменения»
Если появляется это предупреждение, программа была скомпилирована с изменениями, которые еще не были зафиксированы в репозитории git: исполняемый файл не соответствует строго ни одному коммиту.
