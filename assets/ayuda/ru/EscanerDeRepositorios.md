# 🔍 Автоматический сканер папок с кодом

Если у вас уже есть проект программирования на компьютере или папка с исходным кодом, вам не нужно создавать интеллект-карту узел за узлом с нуля. **Сканер кода** MMCelt считывает структуру вашего проекта и автоматически создает интерактивную визуальную карту за считанные секунды.

### 🛠️ Как использовать сканер с максимальной пользой:

**🧠 Зачем сканировать ваш код?**
Преобразуя папку с файлами в интеллект-карту, вы получаете:
- **Обзор архитектуры с высоты птичьего полета:** Быстрое понимание того, как организованы ваши модули, библиотеки и компоненты, без блуждания по десяткам подпапок.
- **Прямые ссылки на ваши файлы:** Каждый блок карты связывается с его реальным путем на диске (`file_path`), что позволяет вам и ИИ точно знать, какой физический файл соответствует каждому понятию.
- **Идеальную отправную точку для работы с ИИ:** Вы можете попросить любую модель искусственного интеллекта проанализировать полученную структуру, обнаружить дублирующийся код, предложить рефакторинг или выявить циклические зависимости.

**Шаги для запуска сканера:**
1. На верхней панели откройте меню **`📁 Файл`** → **`🔍 Сканировать папку с кодом...`**.
2. Появится системный диалог для выбора корневой папки вашего репозитория или программного проекта.
3. MMCelt безопасно исследует дерево каталогов:
   - **Фильтрует технический шум:** Автоматически исключает тяжелые папки сборки и зависимостей, не несущие смысловой ценности (такие как `node_modules/`, `target/`, `dist/`, `.git/`, виртуальные окружения Python и т. д.).
   - **Создает иерархию:** Размещает главную папку в центре и ветвит ключевые модули, пакеты и файлы кода.
4. После создания карты вы можете переупорядочивать узлы по своему вкусу, менять цвета, добавлять пояснительные заметки или отмечать области для доработки.

**🤖 Следующий шаг с ИИ:**
После сканирования вашего кода:
- Используйте `🤖 Искусственный интеллект` → `👁️ Предпросмотр Markdown для ИИ (.md)...`, чтобы увидеть архитектурную сводку.
- Отправьте проект вашему предпочитаемому консольному агенту (`📤 Отправить в...`) или экспортируйте для консультации в веб-чате. ИИ будет точно знать, где находится каждый файл!
