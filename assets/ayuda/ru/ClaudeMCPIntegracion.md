# 🟣 Сервер MCP и агенты ИИ

Прямой и безопасный мост, позволяющий моделям искусственного интеллекта читать и создавать интеллект-карты на вашем компьютере.

### ⚡ Простое подключение в один клик

Вам не нужно вручную редактировать сложные файлы конфигурации. Подключить агентов можно прямо из приложения:

1. Перейдите в меню `🤖 Искусственный интеллект` → `🔌 Подключить MMCelt к моим ИИ...`.
2. MMCelt автоматически определит, какие терминальные ассистенты установлены на вашем компьютере (Claude Code, Codex CLI и Gemini CLI).
3. Нажмите кнопку **Подключить** напротив нужного ассистента. Готово!

Если позже вы установите нового ассистента, просто откройте это окно снова: поиск запускается при каждом открытии. Статус «Подключено» гарантирует, что ассистент знает путь к MMCelt и умеет взаимодействовать с ним через `--mcp-server`.

### ⚙️ Ручная настройка и встроенный сервер

Для ручной настройки вашего MCP-клиента добавьте следующую запись в его конфигурационный файл JSON:
```json
{
  "mcpServers": {
    "mmcelt": {
      "command": "C:/путь/к/mmcelt.exe",
      "args": ["--mcp-server"],
      "env": { "MMCELT_WORKSPACE": "C:/путь/к/вашему/проекту" }
    }
  }
}
```

Сервер MCP **встроен непосредственно в исполняемый файл MMCelt**: он не требует внешних сред выполнения или дополнительных зависимостей.

### 🛡️ Полная безопасность: рабочая папка и резервные копии

Ваше спокойствие превыше всего. Когда ИИ-ассистент работает с MMCelt, **он имеет доступ на чтение и запись исключительно внутри папки вашего проекта**. Эта граница определяется переменной окружения `MMCELT_WORKSPACE`.

Любая попытка ИИ обратиться к другим каталогам на диске будет немедленно отклонена. Для дополнительной защиты:
- **Автоматические резервные копии:** Перед тем как агент изменит существующий файл, MMCelt сохраняет копию с точным временем (например, `project.mmcelt.20260918-120000.bak`). Если результат вам не понравится, исходная работа останется нетронутой.
- **Уважение к вашему замыслу:** ИИ может предлагать новые ветви и связи, но **никогда не удалит и не переместит** созданные вами узлы. Всё добавленное ИИ наглядно помечается как «Создано ИИ», чтобы решение об утверждении или правке всегда оставалось за вами.

### 🔨 6 официальных инструментов сервера MCP

Ассистент располагает шестью официальными инструментами, специально созданными для взаимодействия с вами:

- `mmcelt_workspace_info`: Запрашивает разрешённую папку и список карт `.mmcelt` в ней. Это первый инструмент, который проверяет ИИ, чтобы не придумывать несуществующие пути.
- `mmcelt_create_mindmap`: Создаёт новые интеллект-карты в формате `.mmcelt`.
- `mmcelt_read_mindmap`: Читает структуру вашей карты, заметки и открытые вопросы.
- `mmcelt_sync_ai_progress`: Развивает карту, добавляя узлы с ролями, приоритетами и связями.
- `mmcelt_get_human_feedback`: Считывает ваши исправления и директивы перед внесением правок в важные разделы.
- `mmcelt_export_ai_markdown`: Преобразует карту в структурированную сводку в формате Markdown.

### 🌱 Если вы создали карту самостоятельно: уважение к авторству

Агент может расширять карту, но никогда не заменит её полностью. Он добавляет узлы с ролями и метками и проводит связи между отдельными ветвями.
Все добавленные элементы получают отметку о создании ИИ, не могут быть помечены как одобренные вами без подтверждения и никогда не восстановят связь с узлом, помеченным как отклонённый.

### 🏷️ Узлы с одинаковыми названиями

В диаграммах принятия решений естественно повторять общие слова (например, «Да», «Нет» или «В ожидании») в разных ветвях. Если ИИ запрашивает изменение узла, указав лишь повторяющееся название, MMCelt отклоняет неточный запрос и возвращает уникальные идентификаторы всех совпадений, чтобы ассистент уточнил целевой узел. Это исключает случайные ошибки.

### 🧭 Что делать, если в консоли нет установленных ассистентов?

Не беспокойтесь: MMCelt остаётся полностью функциональным даже без терминальных агентов. Вы можете работать с веб-сервисами (ChatGPT, Claude.ai или Gemini) в браузере, используя команды меню `🤖 Искусственный интеллект` → `📋 Копировать мастер-промпт для ИИ...` или `💾 Экспортировать файл .md для ИИ...`. Затем просто вставьте ответ в `🤖 Искусственный интеллект` → `📥 Импортировать из ИИ (ChatGPT, Claude, Gemini)...`, и текст моментально превратится в визуальные узлы.
