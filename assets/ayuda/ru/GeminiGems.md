# 🔵 Интеграция с Gemini CLI

Gemini — семейство моделей искусственного интеллекта от Google, а **Gemini CLI** — официальный инструмент командной строки. MMCelt позволяет напрямую подключиться к Gemini CLI для анализа, расширения и развития ваших интеллект-карт.

### 💻 Использование с Gemini CLI в терминале

1. Перейдите в `🤖 Искусственный интеллект` → `🔌 Подключить MMCelt к моим ИИ...` и подключите Gemini CLI.
2. Откройте карту и выберите `🤖 Искусственный интеллект` → `📤 Отправить в...` → `Gemini CLI`.
3. Ознакомьтесь с предпросмотром документа и задания, которое получит ИИ.
4. Нажмите **Запустить в консоли**. MMCelt автоматически откроет терминал в подготовленном окружении и начнёт отслеживать изменения, чтобы перенести созданные узлы в карту.

### 💡 Советы и подсказки: Бесплатный ключ API и совместимость

Если при запуске Gemini CLI консоль требует аутентификации или возникают сложности с входом через браузер, самым быстрым, прямым и надёжным решением является использование **бесплатного ключа API** Google AI Studio:

1. Войдите в Google AI Studio (`https://aistudio.google.com/app/apikey`) под своей учётной записью Google и нажмите **Create API Key** (Создать ключ API). Это бесплатно.
2. Скопируйте полученный ключ.
3. Настройте переменную окружения перед запуском консоли или в профиле пользователя:
   - **В Windows (PowerShell):**
     ```powershell
     $env:GEMINI_API_KEY="ваш_ключ_здесь"
     ```
   - **В Linux или macOS (Bash/Zsh):**
     ```bash
     export GEMINI_API_KEY="ваш_ключ_здесь"
     ```
4. С этой переменной Gemini CLI будет работать сразу, без дополнительных запросов на вход в браузере.
5. Официальная документация Gemini CLI доступна в репозитории: `https://github.com/google-gemini/gemini-cli`.

**ℹ️ Текущее состояние совместимости учётных записей в Gemini CLI:**
Подтверждено: с 18 июня 2026 года Google отключила интерактивный вход «Sign in with Google» в Gemini CLI для личных аккаунтов, включая бесплатные, Google AI Pro и Ultra.
- **13 сентября 2026 года:** первая проверка на компьютере Директора, с буквальным сообщением: *«This client is no longer supported for Gemini Code Assist for individuals. To continue using Gemini, please migrate to the Antigravity suite of products»*.
- **Затем проверено на нескольких более старых версиях Gemini CLI**, чтобы исключить проблему конкретной версии: результат оказался одинаковым во всех случаях.
- **Подтверждено бесплатным ключом API Google AI Studio**: подключение сработало полностью, создав подтверждённые узлы и связи на диске, без каких-либо ограничений для личных аккаунтов.

Способ с ключом API, описанный выше, **является единственным подтверждённым путём** для личных аккаунтов: интерактивный вход для них больше недоступен.

### 🌐 Gemini в веб-браузере

Если вы предпочитаете не использовать терминал:
1. Экспортируйте карту через `📁 Файл` → `🤖 Экспорт Markdown для ИИ (.md)` (или нажмите `🤖 Искусственный интеллект` → `👁️ Предпросмотр Markdown для ИИ (.md)...`).
2. Откройте сайт Gemini в браузере, вставьте текст и отправьте свой запрос.
3. Скопируйте ответ Gemini и вернитесь в MMCelt: нажмите `🤖 Искусственный интеллект` → `📥 Импортировать из ИИ (ChatGPT, Claude, Gemini)...`, чтобы добавить новые ветви в вашу карту.
