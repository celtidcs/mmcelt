# 🔵 Интеграция с Antigravity CLI (agy)

Google Antigravity — современная платформа разработки от Google, а **Antigravity CLI (`agy`)** — официальный инструмент командной строки, пришедший на смену Gemini CLI. MMCelt позволяет напрямую подключиться к Antigravity CLI для анализа, расширения и развития ваших интеллект-карт.

### 💻 Использование с Antigravity CLI (`agy`) в терминале

1. Перейдите в `🤖 Искусственный интеллект` → `🔌 Подключить MMCelt к моим ИИ...` и нажмите **Подключить** рядом с Antigravity CLI (agy).
2. Откройте карту и выберите `🤖 Искусственный интеллект` → `📤 Отправить в...` → `Antigravity CLI (agy)`.
3. Ознакомьтесь с предпросмотром документа и задания, которое получит ИИ.
4. Нажмите **Запустить в консоли**. MMCelt автоматически откроет терминал, запустив `agy -i` в подготовленном окружении, и начнёт отслеживать изменения, чтобы перенести созданные агентом узлы через MCP в карту.

### 💡 Аутентификация через обычный аккаунт Google

Antigravity CLI работает напрямую с вашим **стандартным аккаунтом Google**:
- Не требуются ключи API Google AI Studio или дополнительные переменные окружения.
- Если вы ещё не вошли в `agy`, инструмент откроет браузер для входа с вашим обычным аккаунтом Google.
- Сервер MCP программы MMCelt регистрируется в `~/.gemini/config/mcp_config.json`, позволяя агенту читать и изменять карту в пределах разрешённой папки проекта.

### 🌐 Gemini в веб-браузере

Если вы предпочитаете не использовать терминал:
1. Экспортируйте карту через `📁 Файл` → `🤖 Экспорт Markdown для ИИ (.md)` (или нажмите `🤖 Искусственный интеллект` → `👁️ Предпросмотр Markdown для ИИ (.md)...`).
2. Откройте сайт Gemini в браузере, вставьте текст и отправьте свой запрос.
3. Скопируйте ответ Gemini и вернитесь в MMCelt: нажмите `🤖 Искусственный интеллект` → `📥 Импортировать из ИИ (ChatGPT, Claude, Gemini)...`, чтобы добавить новые ветви в вашу карту.
