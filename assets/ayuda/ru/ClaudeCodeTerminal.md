# 🟣 Claude Code: MMCelt открывает консоль

Claude Code — официальный терминальный клиент Anthropic, созданный для программирования и работы напрямую с файлами на вашем компьютере.

### Первое подключение

1. Откройте интеллект-карту в MMCelt.
2. Перейдите в меню `🤖 Искусственный интеллект` → `🔌 Подключить MMCelt к моим ИИ...`.
3. Убедитесь, что папка проекта выбрана верно, и нажмите кнопку **Подключить** в строке Claude Code.
4. Если у вас была открыта консоль Claude Code, закройте её и запустите снова, чтобы она обнаружила новое подключение к MMCelt.

### Повседневная работа

1. В меню MMCelt выберите `🤖 Искусственный интеллект` → `📤 Отправить в...` и укажите **Claude Code**.
2. Откроется окно, в котором вы сможете проверить инструкции и контекст, передаваемые ассистенту.
3. Нажмите кнопку **Запустить в консоли**. Вам не нужно открывать терминал вручную: MMCelt сам откроет новую консоль в папке вашего проекта, создаст дело сессии и включит отслеживание в фоновом режиме.
4. Продолжайте диалог с ИИ в этом окне терминала. Когда ассистент предложит или разовьёт идеи на карте, он вызовет инструмент `mmcelt_sync_ai_progress`, и новые узлы сразу появятся на вашем экране.

MMCelt использует сеанс, уже настроенный в Claude Code; программа не запрашивает дополнительные ключи API и не управляет вашей подпиской Anthropic.
