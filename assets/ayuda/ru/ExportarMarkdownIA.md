# 🤖 Экспорт в Markdown и предпросмотр для ИИ

Одно из главных преимуществ MMCelt заключается в том, что программа автоматически преобразует всю графическую интеллект-карту в структурированный текстовый документ Markdown. Этот документ составлен так, чтобы любая модель искусственного интеллекта понимала иерархию, цели и детали вашего проекта с максимальной точностью.

### 📦 Что содержит созданный документ

Сформированный текст не является беспорядочным списком; он следует продуманной логической структуре:
1. **Роль и директивы:** Указывает модели действовать в качестве архитектора и технического консультанта вашего проекта.
2. **Видение проекта:** Включает описание, составленное вами на вкладке «Проект», чтобы ИИ не упускал из виду глобальную цель.
3. **Сводка статусов:** Ключевые метрики карты (количество задач ожидающих, завершенных или находящихся в исследовании).
4. **Иерархическая структура карты:** Каждый узел, подзадача и пояснительная заметка, упорядоченные по уровням заголовков.
5. **Директивы человека:** Четко указывает, какие части вы одобрили, а какие отметили как требующие исправления.
6. **Перекрестные связи и зависимости:** Описывает отношения между ветвями, чтобы ИИ понимал, что блокирует дальнейшую работу.
7. **Вопросы и блокеры:** Выделяет спорные моменты для первоочередного внимания модели.
8. **Встроенная диаграмма Mermaid:** Текстовая блок-схема, которую многие веб-ИИ могут визуализировать прямо в окне чата.
9. **Готовые шаблоны промптов:** Шаблоны частых запросов, готовые для копирования в чат (технический аудит, поэтапное планирование и др.).

### ⚡ Быстрый предпросмотр и экспорт:

**👁️ Предпросмотр Markdown перед экспортом:**
Если вы хотите своими глазами увидеть информацию, передаваемую ИИ, до сохранения файла на диск:
1. Откройте верхнее меню `🤖 Искусственный интеллект` → `👁️ Предпросмотр Markdown для ИИ (.md)...`.
2. Откроется окно, где можно прочесть весь документ, переходить по разделам и проверять перенос заметок, приоритетов и связей.
3. В этом же окне можно внимательно изучить текст или скопировать фрагменты мышью. Это идеальный способ сохранять полный контроль над передаваемыми данными.

**💾 Как экспортировать файл `.md`:**
Когда вы захотите сохранить этот документ на диск:
- **Через меню Файл:** Нажмите `Ctrl + E` или выберите `📁 Файл` > `🤖 Экспорт Markdown для ИИ (.md)`.
- **Через меню Искусственный интеллект:** Перейдите в `🤖 Искусственный интеллект` → `💾 Экспортировать файл .md для ИИ...`.

Полученный файл `.md` можно прикрепить напрямую к веб-чатам ChatGPT, Claude или Gemini либо открыть в любом текстовом редакторе.
