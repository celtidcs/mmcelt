# 🤖 Exportation Markdown et prévisualisation IA

L'un des atouts majeurs de MMCelt est de convertir automatiquement l'intégralité de votre carte mentale visuelle en un document texte structuré en Markdown. Ce document est conçu pour que tout modèle d'intelligence artificielle comprenne la hiérarchie, l'objectif et les détails de votre projet avec une fidélité optimale.

### 📦 Que contient le document généré

Le texte produit n'est pas une liste désordonnée ; il adopte une structure logique très soignée :
1. **Rôle et directives :** Indique au modèle d'agir comme architecte et collaborateur technique de votre projet.
2. **Vision du projet :** Intègre la description rédigée dans l'onglet Projet pour que l'IA ne perde jamais de vue l'objectif global.
3. **Résumé de l'état :** Métriques clés de la carte (nombre de tâches en attente, terminées ou en cours d'étude).
4. **Structure hiérarchique de la carte :** Chaque nœud, sous-tâche et note explicative organisés par niveaux d'en-têtes.
5. **Directives humaines :** Signale clairement quelles parties vous avez validées et lesquelles requièrent des corrections.
6. **Connexions croisées et dépendances :** Décrit les relations entre différentes branches pour que l'IA comprenne ce qui bloque quoi.
7. **Doutes et blocages :** Met en lumière les points marqués de doutes afin que le modèle leur accorde la priorité.
8. **Diagramme Mermaid intégré :** Un organigramme textuel que de nombreuses IA peuvent afficher graphiquement dans leurs interfaces de chat.
9. **Prompts d'action prêts à l'emploi :** Modèles de requêtes fréquentes à copier-coller dans un chat (audit technique, planification par phases, etc.).

### ⚡ Prévisualisation et exportation rapide :

**👁️ Prévisualiser le Markdown avant d'exporter :**
Si vous souhaitez vérifier de vos propres yeux quelles informations seront transmises à l'IA avant d'enregistrer le moindre fichier sur disque :
1. Rendez-vous dans le menu supérieur `🤖 Intelligence artificielle` → `👁️ Aperçu du Markdown pour l'IA (.md)...`.
2. Une fenêtre s'ouvre, vous permettant de lire l'intégralité du document, de parcourir ses sections et de vérifier la transcription de vos notes, priorités et connexions.
3. Depuis cette même fenêtre, vous pouvez relire sereinement le texte ou en copier des passages à la souris. C'est le moyen idéal pour garder la maîtrise absolue de ce que vous partagez.

**💾 Comment exporter le fichier `.md` :**
Lorsque vous souhaitez enregistrer ce document sur votre disque :
- **Depuis Fichier :** Appuyez sur `Ctrl + E` ou allez dans `📁 Fichier` > `🤖 Exporter le Markdown pour l'IA (.md)`.
- **Depuis Intelligence artificielle :** Allez dans `🤖 Intelligence artificielle` → `💾 Exporter le fichier .md pour l'IA...`.

Le fichier `.md` résultant peut être directement téléversé dans des chats web tels que ChatGPT, Claude ou Gemini, ou ouvert dans n'importe quel éditeur de texte pour votre propre lecture.
