# 🟣 Claude Code : MMCelt ouvre la console

Claude Code est le client terminal officiel d'Anthropic, conçu pour programmer et travailler directement avec les fichiers de votre machine.

### Première connexion

1. Ouvrez votre carte mentale dans MMCelt.
2. Allez dans le menu `🤖 Intelligence artificielle` → `🔌 Connecter MMCelt à mes IA...`.
3. Vérifiez que le dossier de projet est correct et cliquez sur le bouton **Connecter** sur la ligne de Claude Code.
4. Si vous aviez une console Claude Code ouverte, fermez-la puis rouvrez-la afin qu'elle détecte la nouvelle connexion avec MMCelt.

### Au quotidien

1. Dans le menu de MMCelt, choisissez `🤖 Intelligence artificielle` → `📤 Envoyer à...` et sélectionnez **Claude Code**.
2. Une fenêtre s'ouvrira pour vous permettre de vérifier les instructions et le contexte qui seront transmis à l'assistant.
3. Cliquez sur le bouton **Démarrer dans la console**. Pas besoin d'ouvrir un terminal manuellement : MMCelt se charge d'ouvrir une nouvelle console dans le dossier de votre projet, crée le dossier de session et active la surveillance en arrière-plan.
4. Poursuivez la conversation avec l'IA dans cette fenêtre de terminal. Lorsque l'assistant propose ou développe des idées sur la carte, il utilisera l'outil `mmcelt_sync_ai_progress` et vous verrez apparaître les nouveaux nœuds directement sur votre écran.

MMCelt tire parti de la session déjà configurée dans Claude Code ; il ne vous demandera pas de clé d'API supplémentaire ni ne gérera votre facturation Anthropic.
