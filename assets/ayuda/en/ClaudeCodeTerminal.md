# 🟣 Claude Code: MMCelt opens the console

Claude Code is Anthropic's official terminal client, designed for coding and working directly with the files on your machine.

### The first time

1. Open your mind map in MMCelt.
2. Go to the menu `🤖 Artificial Intelligence` → `🔌 Connect MMCelt with my AIs...`.
3. Check that the project folder is correct and click the **Connect** button on the Claude Code row.
4. If you had any Claude Code console open, close it and restart it so it detects the new connection with MMCelt.

### For each job

1. In the MMCelt menu, choose `🤖 Artificial Intelligence` → `📤 Send to...` and select **Claude Code**.
2. A window will open where you can review the instructions and context to be sent to the assistant.
3. Click the **Start in console** button. You don't need to open a terminal manually: MMCelt takes care of opening a new console in your project folder, creates the work record, and starts watching in the background.
4. Continue the conversation with the AI in that terminal window. When the assistant proposes or expands ideas on the map, it will use the `mmcelt_sync_ai_progress` tool and you will see the new nodes appear directly on your screen.

MMCelt uses the session you already have configured in Claude Code; it will not ask for additional API keys or manage your Anthropic billing.
