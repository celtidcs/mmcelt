# 📥 Two-Way Import from AI

Brings any project, conversation, or specification generated by ChatGPT, Claude, or Gemini into MMCelt.

### 🔄 How to use it:
1. In MMCelt go to **`🤖 Artificial Intelligence` > `📋 Copy Master Prompt for AI...`**.
2. Paste that prompt into your AI chat along with your ideas, code, or documentation.
3. The AI returns a structured JSON block.
4. In MMCelt go to **`🤖 Artificial Intelligence` > `📥 Import from AI (ChatGPT, Claude, Gemini)...`**.
5. Paste the returned block and click **`✨ Replace map with AI output`**.
6. MMCelt reconstructs the full map with notes, tags, statuses, code paths, and automatic layout.

### ⚠️ Importing replaces the map, it does not append
The currently open map **is replaced**: incoming AI content takes its place and is not merged with existing nodes.

Before replacing, MMCelt saves a backup of your previous map. If you realize you did not want to import, restart the program: on startup it will offer to restore that map.

Nevertheless, good practice is to **save with `Ctrl + S` before importing**. The recovery backup is a safety net, not a substitute for saving.

### 🎨 What does not travel in JSON
The AI returns structure and content, not layout presentation. Manual positions and collapsed branches are reset upon import: the map is arranged using automatic layout.

Everything essential for development travels intact: titles, notes, file paths, tags, roles, statuses, priorities, cross links, and required corrections.
