# 🔵 Integration with Antigravity CLI (agy)

Google Antigravity is Google's advanced development platform, and **Antigravity CLI (`agy`)** is its official command-line tool replacing the legacy Gemini CLI. MMCelt lets you connect directly with Antigravity CLI to analyze, expand, and enrich your mind maps.

### 💻 Using Antigravity CLI (`agy`) in the Terminal

1. Go to `🤖 Artificial Intelligence` → `🔌 Connect MMCelt with my AIs...` and click **Connect** next to Antigravity CLI (agy).
2. Open your map and select `🤖 Artificial Intelligence` → `📤 Send to...` → `Antigravity CLI (agy)`.
3. Review the preview of the document and prompt that the AI will receive.
4. Click **Start in Console**. MMCelt will automatically open the terminal running `agy -i` with the environment prepared and begin watching for changes to merge nodes created by the agent via MCP.

### 💡 Authentication with Standard Google Account

Antigravity CLI works natively with your **standard Google account**:
- No Google AI Studio API keys or additional environment variables are needed.
- If you have not logged into `agy` yet, the tool will open your browser to log in with your normal Google account.
- MMCelt's MCP server is registered in `~/.gemini/config/mcp_config.json`, enabling the agent to read and update the map within the authorized project directory.

### 🌐 Gemini in the Web Browser

If you prefer not to use the terminal:
1. Export your map with `📁 File` → `🤖 Export Markdown for AI (.md)` (or click `🤖 Artificial Intelligence` → `👁️ Preview AI Markdown (.md)...`).
2. Go to the Gemini website in your browser, paste the text, and ask your question.
3. Copy the answer generated by Gemini and return to MMCelt: click `🤖 Artificial Intelligence` → `📥 Import from AI (ChatGPT, Claude, Gemini)...` to incorporate new branches into your map.
