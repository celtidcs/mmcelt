# 🔍 Interface Scale

App text looks small on a large display or TV? Everything — fonts, buttons, and panels — can be scaled between 50% and 300%.

### ⌨️ Shortcuts
- **Ctrl +** Zoom in / Enlarge UI
- **Ctrl -** Zoom out / Reduce UI
- **Ctrl 0** Reset to default scale

### 📋 From the menu
**🎨 View & Layout → Interface Scale**, with five presets. The **200% preset is tailored for TVs** and viewing from a sofa.

**Scale setting persists across restarts**, alongside visual theme. Set once and done.

### ⚠️ Distinct from canvas zoom
These are separate controls and easy to confuse:

- **Mouse Wheel**: Zooms **the mind map**. UI font and button sizes remain unchanged.
- **Ctrl + / Ctrl -**: Scales **the UI**: menus, buttons, and inspector text.

If buttons and menus appear small, use interface scale.

### 🖥️ Why doesn't it auto-scale?
Partially it does: on 4K displays without OS DPI scaling, default size increases initially.

However, optimal scale depends on **viewing distance**, which software cannot infer: a 42-inch TV at 3 meters presents identical resolution data as a 24-inch monitor at 50 cm. MMCelt offers sensible defaults and remembers your preferred choice.
