# 🤖 Markdown Export & AI Preview

One of the great advantages of MMCelt is that it automatically converts your entire visual mind map into a structured text document in Markdown. This document is designed so that any artificial intelligence model understands the hierarchy, purpose, and details of your project with maximum fidelity.

### 📦 What the generated document contains

The generated text is not a disordered list; it follows a carefully crafted logical structure:
1. **Role and directives:** Instructs the model to act as a system architect and technical collaborator for your project.
2. **Project vision:** Includes the description you wrote in the Project tab so the AI never loses sight of the overall goal.
3. **Status summary:** Key map metrics (how many tasks are pending, completed, or in research).
4. **Hierarchical map structure:** Every node, subtask, and explanatory note organized by heading levels.
5. **Human directives:** Clearly highlights which parts you have approved and which parts you marked as needing correction.
6. **Cross connections and dependencies:** Describes relationships between different branches so the AI understands what blocks what.
7. **Blockers and questions:** Highlights points marked with doubts so the model gives them top priority.
8. **Embedded Mermaid diagram:** A text-based flowchart that many web AIs can render visually in their chat interfaces.
9. **Ready-to-use action prompts:** Frequently asked question templates that you can copy and paste into a chat (technical audit, phased planning, etc.).

### ⚡ Quick preview and export:

**👁️ Previewing Markdown before exporting:**
If you want to see with your own eyes what information will be sent to the AI before saving any file to disk:
1. Go to the top menu `🤖 Artificial Intelligence` → `👁️ Preview AI Markdown (.md)...`.
2. A window will open where you can read the complete document, navigate through its sections, and verify how your notes, priorities, and connections were translated.
3. From that same window you can review the text calmly or copy excerpts directly with the mouse. It is the ideal way to maintain absolute control over what you share.

**💾 How to export the `.md` file:**
When you want to save this document to your disk:
- **From File:** Press `Ctrl + E` or go to `📁 File` > `🤖 Export Markdown for AI (.md)`.
- **From Artificial Intelligence:** Go to `🤖 Artificial Intelligence` → `💾 Export .md File for AI...`.

The resulting `.md` file can be attached directly in web chats like ChatGPT, Claude, or Gemini, or opened with any text editor to read it yourself.
