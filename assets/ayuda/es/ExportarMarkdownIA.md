# 🤖 Exportación de Markdown y Previsualización para la IA

Una de las grandes ventajas de MMCelt es que convierte automáticamente todo tu mapa mental gráfico en un documento de texto estructurado en Markdown. Este documento está diseñado para que cualquier modelo de inteligencia artificial entienda la jerarquía, el propósito y los detalles de tu proyecto con máxima fidelidad.

### 📦 Qué contiene el documento generado

El texto generado no es una lista desordenada; sigue una estructura lógica muy cuidada:
1. **Rol y directrices:** Indica al modelo que actúe como arquitecto y colaborador técnico de tu proyecto.
2. **Visión del proyecto:** Incluye la descripción que redactaste en la pestaña Proyecto para que la IA no pierda de vista el objetivo global.
3. **Resumen de estado:** Métricas clave del mapa (cuántas tareas hay pendientes, completadas o en investigación).
4. **Estructura jerárquica del mapa:** Cada nodo, subtarea y nota explicativa organizada por niveles de encabezado.
5. **Directivas humanas:** Señala claramente qué partes has aprobado tú y qué partes marcaste como pendientes de corrección.
6. **Conexiones cruzadas y dependencias:** Describe las relaciones entre ramas distintas para que la IA entienda qué bloquea a qué.
7. **Dudas y bloqueos:** Destaca los puntos marcados con dudas para que el modelo les dé prioridad.
8. **Diagrama Mermaid embebido:** Un diagrama de flujo en texto que muchas IAs pueden dibujar visualmente en sus chats.
9. **Prompts de acción listos para usar:** Plantillas de preguntas frecuentes que puedes copiar y pegar en un chat (auditoría técnica, planificación por fases, etc.).

### ⚡ Previsualización y exportación rápida:

**👁️ Previsualizar el Markdown antes de exportar:**
Si quieres ver con tus propios ojos qué información se enviará a la IA antes de guardar ningún archivo en disco:
1. Ve al menú superior `🤖 Inteligencia Artificial` → `👁️ Previsualizar Markdown de IA (.md)...`.
2. Se abrirá una ventana donde podrás leer el documento completo, navegar por sus secciones y comprobar cómo se han traducido tus notas, prioridades y conexiones.
3. Desde esa misma ventana puedes revisar el texto con calma o copiar fragmentos directamente con el ratón. Es la forma ideal de tener control absoluto sobre lo que compartes.

**💾 Cómo exportar el archivo `.md`:**
Cuando quieras guardar este documento en tu disco:
- **Desde Archivo:** Pulsa `Ctrl + E` o ve a `📁 Archivo` > `🤖 Exportar Markdown para IA (.md)`.
- **Desde Inteligencia Artificial:** Ve a `🤖 Inteligencia Artificial` → `💾 Exportar Archivo .md para IA...`.

El archivo `.md` resultante puedes adjuntarlo directamente en chats web como ChatGPT, Claude o Gemini, o abrirlo con cualquier editor de texto para leerlo tú mismo.
